# TaskFlow Pro

업무 흐름을 효율적으로 관리하는 태스크 관리 웹 애플리케이션입니다.

## 기능

- 태스크 생성, 수정, 삭제
- 상태별 칸반 보드 (할 일 / 진행 중 / 완료)
- 우선순위 설정
- 마감일 관리

## 시작하기

```bash
# 저장소 클론
git clone https://github.com/wngmls/kosta-taskflow-pro.git
cd kosta-taskflow-pro

# 브라우저에서 index.html 열기
```

## 기술 스택

- HTML5
- CSS3
- JavaScript (Vanilla)
